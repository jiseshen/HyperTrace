# HyperTrace X launch package

Use the images in this order for the X post. The draft contains upload placeholders:

1. `hypertrace-results.png`: main results graphic.
2. `../head.jpg`: visual comparison of summary, memory, and hypothesis approaches (PNG data despite the filename).
3. `../main.jpg`: HyperTrace workflow (PNG data despite the filename).

`hypertrace-results.svg` is the editable vector source for the first image. The curve uses the plotted coordinates from the paper's original Figure 3 SVG for HyperTrace and Dynamic Cheatsheet only. The two stress-test bar charts use Table 5 values. The main-curve callout uses Table 3 values. The graphic simplifies the labels to “Ours” and “Memory-based”; the underlying comparator is Dynamic Cheatsheet.

Source: [HyperTrace paper](https://arxiv.org/html/2609.09835v1), Figures 3 and Tables 3 and 5. The paper is CC BY 4.0. The launch text is in `x-thread.md`.
